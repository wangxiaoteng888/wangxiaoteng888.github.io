为什么 slot / group / region 不是一一对应？
  • QSA main 和 compressed 在同一个 group，却使用 R2、R3、R5 三个 region。
  • GDN 的 conv 与 ssm 使用 R1、R2。R2 因此被两类 group 复用，但它们不能同时拥有同一物理 block ID。
  • QSA source 的 main/raw/compressed 使用相同 slot 序号；raw 有独立 block table，所以不必使用与 main 相同的 block ID。
  • 36 个 GDN owner 使用 slot 0～35；12 组 QSA source 使用 slot 0～11；此例 1 个 PLE owner 使用 slot 0。
  • 整个 block ID 的分配由同一个 BlockPool 管理，即便部分 region 未使用，也不会单独将这些部分分配给另一 group。
  • 同 group 的多个请求可以通过 prefix cache 共享 block。这不允许两个有冲突布局的 group 同时占用同一个 block。
