02 / MULTI-HEAD LATENT ATTENTION

多个头的 K、V，
可以从一份小向量生成。

MLA = 多头潜在注意力。先用一个小例子看懂 KV 联合压缩，再看 解耦 RoPE，最后验证：不展开历史 K、V，也能得到相同的结果。

X → Cᴷⱽ → 各个头的 Kᶜ、V
X → Kᴿ → 共享的位置分支推理时缓存：每个 token 的 Cᴷⱽ + Kᴿ。
压缩特征表示；仍可关注全部允许的历史 token。
B=1 · T=3一句话：「我 / 爱 / 学习」
D=4 · H=2输入四维 · 两个注意力头
d꜀=2 · d_q=2KV 压缩维度 · Query 压缩维度
dₖ=2 · dᵥ=2每头内容 Key 维度 · Value 维度
dᵣ=2每头 Query 的 RoPE 维度；Key 端共享

教学约定：所有向量按“行”存放，投影写成 X @ W；数值人工构造。省略 bias、归一化、dropout、量化和长上下文缩放。此处 dₖ 专指内容维度，加入位置分支后 Q/K 总维度为 dₖ+dᵣ。

对应代码：展开路径与吸收路径

以下是单个 batch 的伪代码；矩阵形状与页面一致。C 表示本页的 Cᴷⱽ。split_heads 把 [T,H·d] 变成 H 个 [T,d] 矩阵。实际框架通常把各个头批量计算。

X: [T,D] = [3,4]
C = X @ W_DKV                    # [3,2]：KV latent
CQ = X @ W_DQ                    # [3,2]：Query latent
Qc = split_heads(CQ @ W_UQ)      # H 个 [3,2]
Kc = split_heads(C  @ W_UK)      # H 个 [3,2]
V  = split_heads(C  @ W_UV)      # H 个 [3,2]

# 独立位置分支；关闭教学开关时省略
Qr = RoPE(split_heads(CQ @ W_QR)) # H 个 [3,2]
Kr = RoPE(X @ W_KR)               # [3,2]，各个头共享

# 路径一：展开完整 K、V，便于理解
for h in range(H):
    S[h] = Qc[h] @ Kc[h].T + Qr[h] @ Kr.T
    A[h] = softmax(S[h] / sqrt(dk + dr) + mask, dim=-1)
    Z[h] = A[h] @ V[h]            # [3,2]
Y = concat(Z, dim=-1) @ W_O       # [3,4]

# 路径二：不展开历史 Kc、V
for h in range(H):
    UKh = W_UK[:, h*dk:(h+1)*dk]  # [dc,dk]
    UVh = W_UV[:, h*dv:(h+1)*dv]  # [dc,dv]
    WOh = W_O[h*dv:(h+1)*dv, :]  # [dv,D]
    Qhat = Qc[h] @ UKh.T          # [3,dc]
    S[h] = Qhat @ C.T + Qr[h] @ Kr.T
    A[h] = softmax(S[h] / sqrt(dk + dr) + mask, dim=-1)
    L[h] = A[h] @ C               # [3,dc]
    Fh = UVh @ WOh                # [dc,D]；只依赖权重
Y = sum(L[h] @ Fh for h in range(H))

# 解码时每层、每个 token 的紧凑缓存：
# C[token] [dc] + Kr[token] [dr]
# 实际可缓存归一化后的 C；本页为手算省略归一化。
为什么 RoPE 必须分开处理？

在线性内容分支中，Qc @ (C @ UK)ᵀ 可以重排成 (Qc @ UKᵀ) @ Cᵀ。若在展开后的 Key 上再施加随位置变化的旋转，旋转矩阵就夹在投影之间，通常无法吸收到一套固定权重中。

解耦 RoPE 给 Q/K 额外增加一个位置分支：内容部分保留可重排的线性结构；位置部分单独旋转、单独计算点积，再把两部分分数相加。Key 的位置分支在多个头之间共享，但 Query 的位置分支按头区分。

“压缩”是不是把原来的 MHA 无损打包？

不是。MLA 的低秩结构是模型的参数化方式。它直接从 X 生成 latent，再由 latent 生成各头的内容 K 与 V；不能保证恢复任意一个已有 MHA 的 K/V。本页最后两条路径的等价，指同一个 MLA、同一组权重的代数重排，不表示它与前一个 MHA 网页的输出相同。

共享 latent 也不等于多个头有相同的 K/V。它们从同一份表示出发，但乘的是不同的权重块。

MLA 与稀疏注意力

本页的注意力仍对所有允许的 key 计算。因果遮罩之外没有做 token 筛选。MLA 的压缩发生在特征表示中；稀疏注意力则限制 query–key 连接，两者可以组合。

KV Cache 与模型权重

缓存按 token 增长，每个新位置都要追加 Cᴷⱽ 和 Kᴿ。投影权重由同一层的所有 token 共用，不会每生成一个词就新增一份。这里只比较缓存元素数，不估算峰值显存或运行速度。
