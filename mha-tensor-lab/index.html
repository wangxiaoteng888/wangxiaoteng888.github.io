完整实现：让代码和图一一对应

下面是 PyTorch 风格的核心流程。权重按 [输入维, 输出维] 存放，因此使用 X @ W。省略 bias、dropout；这里从已准备好的隐藏状态 X 开始，不再计算 embedding 或位置编码。

B, T, D = X.shape                     # [1, 3, 4]
H, dk, dv = 2, 2, 2
Q = X @ WQ                            # [1, 3, 4]
K = X @ WK                            # [1, 3, 4]
V = X @ WV                            # [1, 3, 4]

Q = Q.reshape(B, T, H, dk)             # [1, 3, 2, 2]
K = K.reshape(B, T, H, dk)
V = V.reshape(B, T, H, dv)
Q = Q.transpose(1, 2)                 # [1, 2, 3, 2]
K = K.transpose(1, 2)
V = V.transpose(1, 2)

KT = K.transpose(-2, -1)              # [1, 2, 2, 3]
S = Q @ KT                            # [1, 2, 3, 3]
S = S / (dk ** 0.5)                   # [1, 2, 3, 3]
if causal:
    future = torch.ones(T, T, dtype=torch.bool,
                        device=X.device).triu(diagonal=1)
    S = S.masked_fill(future, float('-inf'))
A = torch.softmax(S, dim=-1)          # [1, 2, 3, 3]
Z = A @ V                             # [1, 2, 3, 2]

Z = Z.transpose(1, 2)                 # [1, 3, 2, 2]
C = Z.contiguous().view(B, T, H * dv)  # [1, 3, 4]
Y = C @ WO                            # [1, 3, 4]
拓展：残差连接和 LayerNorm 在哪里？

MHA 到 Y 就已结束。原始 Transformer 的 Post-LN 注意力子层还会计算 R = X + Y，再计算 LayerNorm(R)。这两步都保持 [1, 3, 4]。LayerNorm 在每个 token 的 4 个特征上求均值与方差；完整形式是 γ ⊙ (R − μ) / √(σ² + ε) + β。本示例省略 dropout。

Pre-LN 结构把归一化移到 MHA 输入之前，写成 X + MHA(LayerNorm(X))。所以“残差和归一化的位置”取决于模型结构，不能把它们当成 MHA 内部固定步骤。

KEEP THIS MAP / 维度速查

记住：token 轴和特征轴各有自己的任务。

以下列出所有操作。Q/K/V 的投影各自执行；第 03–10 步的注意力计算对每个 batch、每个 head 独立进行。

为什么中间会出现 T × T？

每个 query 都要和每个 key 算一次匹配分数。三行代表三个“发问的位置”，三列代表三个“被查看的位置”。这是关系矩阵，不是新的 token 特征。

为什么多头不是分句子？

每个头都保留全部 3 个 token。拆分的是投影后的特征通道 4 = 2 × 2。每个头使用独立的投影参数块，能形成不同的注意力分布。

为什么输出还是 4 维？

两个头各输出 2 维，沿特征轴拼起来得到 4 维；Wᴼ 再混合各头的信息。本例采用常见设置 H·dᵥ = D，其他设置也可以由 Wᴼ 投影回 D。
