MULTI-HEAD LATENT ATTENTION

每个 token 只存一份压缩内容，
各个头仍然能算自己的注意力。

MLA 的核心是减少每个 token 的 KV 存储：把各个头的 K、V 内容建立在共享向量 C 上，再利用矩阵乘法的结合律，直接在压缩空间计算。这里先画直观的展开路径，再画等价的吸收路径。

B=1 · T=5 · D=4一个序列，五个已知 token，输入四维
H=2 · dₙ=dᵣ=dᵥ=2两个主头；内容、RoPE、Value 每头各两维
d꜀=3 · d_q=2KV 压缩三维；Query 压缩两维

本页采用新的教学权重，把 d꜀ 从之前例子的 2 改成 3，专门让“压缩维度”和“每头维度”的差别可见。输入仍是「我 / 昨天 / 在 / 图书馆 / 学习」。无旧缓存；保留因果遮罩；省略 RMSNorm 等不影响此处代数对照的细节。

先看最后到底存了什么

每层、每个 token 存 Cᴷⱽ 的 3 个数 + Kᴿ 的 2 个数。五个 token 的逻辑缓存可拼成 [1,5,5]：

绿色三列是压缩内容 C；橙色两列是已旋转的位置 Key。实际可分成两块缓存，不要求物理拼接。Q 不作为历史 KV 缓存保存。

为什么值得这样存？

按本例维度，若像普通 MHA 一样缓存每头的完整 K、V：

每 token：2 头 × (K 4 维 + V 2 维) = 12 个数
MLA 每 token：C 3 维 + Kᴿ 2 维 = 5 个数

五个 token 是 60 → 25 个数 / 层。在相同存储精度下，缓存更小，解码时读取历史 KV 的数据量也随之减少。

这是本教学配置的元素数对比，不是实际模型的固定压缩比，也不是总计算量或总显存的比例。若展开 MLA 时已共享 Kᴿ，则其展开缓存是每 token 10 个数；压缩后仍是 5 个。

两条路径为什么可以得到相同结果？

内容打分：把 K 的展开挪到 Q 这一边

展开：Kᶜ_h = C Uᴷ_h Sᶜ_h = Qᶜ_h (Kᶜ_h)ᵀ 等价：Sᶜ_h = (Qᶜ_h Uᴷ_hᵀ) Cᵀ Q̂_h = Qᶜ_h Uᴷ_hᵀ [5,2] × [2,3] → Q̂_h [5,3] [5,3] × [3,5] → Sᶜ_h [5,5]

只是把括号换了位置，没有交换矩阵顺序。新 Q̂ 是 3 维，恰好能与缓存 C 的 3 维做点积，历史 Kᶜ 无需显式展开。

加权求和：先汇总 C，再展开 V

展开：V_h = C Uⱽ_h Z_h = A_h V_h 等价：Z_h = (A_h C) Uⱽ_h L_h = A_h C [5,5] × [5,3] → L_h [5,3] [5,3] × [3,2] → Z_h [5,2]

当前 query 先对共享 C 加权；求和之后才做上投影。无需为每个历史位置、每个头生成 V。Uⱽ_h 还可进一步与对应的 Wᴼ_h 行块合并。

为什么把 RoPE 单独分出去？

先有位置，才能区分“谁在前、谁在后”

只用内容 Q·K，匹配分数本身没有显式的位置旋转项。RoPE 对每个 token 的成对维度按位置旋转，点积时便能包含两个位置的相对关系。

示意：[1,0] 位置 0：旋转 0° 位置 1：旋转 45° 点积含相对角度

45° 是教学设定；真实 RoPE 的频率由维度及配置决定。RoPE 与因果遮罩是不同操作。

位置相关的旋转会妨碍固定投影的吸收

如果把展开后的内容 Kᶜ 也整体做位置旋转，内容打分中就会夹入随 query/key 位置变化的旋转矩阵。它通常不能与上投影任意交换，也无法统一吸收到一套与位置无关的固定权重里。

内容分支：Qᶜ、Kᶜ 不加 RoPE → 保留 Q̂ Cᵀ 的吸收写法 位置分支：Qᴿ、Kᴿ 单独做 RoPE → 单独算 Qᴿ(Kᴿ)ᵀ 总分数 = 内容分数 + 位置分数 再缩放、加 mask、softmax

因此保留一份较小、主头间共享的 Kᴿ 缓存。这里不是取消位置信息，而是让位置计算与可吸收的内容计算分开。

“压缩”不是把任意 MHA 无损打包

MLA 从训练时就使用这种结构。各头内容 K/V 由同一个低维 C 产生，是一种低秩参数化。这里 [Kᶜ_flat | V_flat] = C [Uᴷ | Uⱽ]，其秩至多为 d꜀=3。它并不保证可以复原任意独立 MHA 的 K/V。

精确相等的是：同一套 MLA 权重下，展开路径与吸收路径的数学结果。

为什么 Query 也降维？

Cᴽ 与 Cᴷⱽ 是两套不同投影。Query 低秩投影有助于降低训练时的激活内存等开销，但历史 Query 本来就不是 KV Cache 的内容；不能把它算进 KV 缓存节省。

同一个 C 被不同 Uᴷ_h、Uⱽ_h 读取，所以不同头仍可得到不同的 K/V，并形成不同注意力分布。

进入逐 token 解码后，形状如何变？

若前 4 个 token 已缓存，现在处理位置 4：当前 X 是 [1,1,4]，当前 Q 是 [1,2,1,2]，历史 C 是 [1,5,3]、Kᴿ 是 [1,5,2]；注意力分数为 [1,2,1,5]，输出为 [1,1,4]。

新增一行 C、Kᴿ；之前的缓存持续复用。使用吸收路径时，无需每轮重新展开全部历史 K/V。

MLA 和刚才的 DSA 分别省在哪里？

MLA 主要减少每个位置存储的 KV 表示，并支持压缩空间计算；本页仍读取全部因果合法位置。DSA 则额外用 Indexer 选择部分位置。

缓存减少不等于所有 FLOPs 按同一比例减少。吸收后的内容维度是 d꜀，实际性能还与形状、精度、内核和硬件有关。

范围：DeepSeek 式 MLA。全页采用行向量记法 XW，因此权重维度可能与论文的列向量记法互为转置。维度、数值均为小型教学例子，不代表具体模型配置。
